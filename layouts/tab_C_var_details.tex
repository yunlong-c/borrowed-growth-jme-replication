\textit{Notes:} This table reports $R^2$ statistics and slope-test $p$-values for predictive regressions
\[y_{t+1}=\alpha_y+\beta_y z_t^{EE}+\varepsilon_{t+1},\]
where $y_{t+1}$ is the total log market return, expected return, cash-flow news, or discount-rate news, expressed in percentage points, and $z_t^{EE}$ is standardized EE mobility in economic month $t$. Return components are obtained from the \citet{Campbell1991} VAR decomposition. Each VAR contains the total return and the log dividend--price ratio, together with the additional variable or principal components identified in the first column. PC1--3 are the first three principal components of the twelve financial predictors excluding DE and TMS; EP and DE span the same information set conditional on DP. Within each VAR specification, all four predictive regressions use the same valid origins and EE scale. The reported $R^2$ values measure the fit of these EE regressions and are expressed in percent. The $p$-values test $\beta_y=0$ using Newey--West standard errors with one monthly lag and a two-sided normal approximation. $N$ is the number of projection observations. The slope coefficients satisfy $\beta_r=\beta_{ER}+\beta_{CF}-\beta_{DR}$. Appendix \ref{app:var} provides the component construction and sample details.\par\end{minipage}
