The decomposition satisfies $r=ER+N_{CF}-N_{DR}$. For the baseline VAR, the total-return slope is $-0.2759$ ($t_{\mathrm{NW}}=-1.19$). The slope identity is $-0.2759=-0.1574-0.1159-0.0026$, up to rounding. Return components are expressed in monthly log-return percentage points, so the coefficients measure monthly log-return percentage points per one-standard-deviation increase in EE. ``PC1--3'' indicates that the VAR includes the first three principal components extracted from the twelve financial predictors excluding DE and TMS. EP and DE span the same information set conditional on DP and therefore enter as a single specification. The $t$ columns report Newey--West statistics with one lag. *, **, and *** denote significance at the 10\%, 5\%, and 1\% levels, respectively.
