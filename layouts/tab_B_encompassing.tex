\textit{Notes:} This table reports forecast encompassing tests between EE and each alternative predictor at horizons of $h=1,3,6,12$ months. The combination forecast is
\[\widehat y^{\,c}_{t,h}=(1-\lambda)\widehat y^{\,base}_{t,h}
+\lambda\widehat y^{\,add}_{t,h},\qquad 0\leq\lambda\leq1.\]
Column group A treats the comparator as the base forecast and EE as the added forecast; column group B reverses these roles. The reported $\widehat\lambda$ is the least-squares weight on the added forecast, constrained to $[0,1]$ and estimated over the common evaluation sample. These weights describe forecast complementarity and are not recursively estimated portfolio or combination weights. The $t_{HLN}$ columns report the modified Harvey--Leybourne--Newbold statistic for the null that the base forecast encompasses the added forecast against the alternative that the added forecast contains incremental information. Tests use a horizon-$h$ heteroskedasticity- and autocorrelation-consistent variance estimate and one-sided probabilities. $^{*}$, $^{**}$, and $^{***}$ denote rejection at the 10\%, 5\%, and 1\% levels, respectively. Appendix \ref{app:B-combination} provides the test construction and sample details.\par\end{minipage}
