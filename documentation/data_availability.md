# Data availability and redistribution

This code-only empirical release distributes no external data or generated
results. The full path, vintage and schema register is `data_acquisition.csv`;
the README provides acquisition instructions.

BLS numerical series are public domain. Other files retain source-specific
terms; FRED does not replace the original producer's conditions. Goyal–Welch
includes CRSP-derived fields without a documented redistribution grant in
the author package. Philadelphia Fed FMP, Atlanta Fed wage data, Cboe SKEW,
NY Fed SCE and author-produced indices are obtained from their publishers.

The Federal Reserve financial-stability HTML includes third-party data credits;
its government host does not establish a blanket redistribution grant.
The CTYZ attention workbook and VIX input are not used by this release.

Reconstructed series, observation ledgers, forecasts, residuals and bootstrap
innovations remain local outputs. Code and seeds regenerate them; no frozen
data-dependent arrays are included. The package's code/documentation licenses
do not authorize redistribution of provider data.
